# CS Trim - אתר הנחיתה וההפצה הרשמי

אתר נחיתה מודרני, מהיר ורספונסיבי בעברית מלאה (RTL) להפצת תוסף **CS Trim** ל-Adobe Premiere Pro לקהל הרחב.

---

## 🌟 מה כולל האתר?

1. **עיצוב מודרני Dark Mode פרימיום:**
   - תואם לממשק של Adobe Premiere Pro וכלי עריכה מובילים.
   - טיפוגרפיה איכותית (פונט Heebo מבית Google Fonts).
   - תמיכה מלאה בכל גדלי המסכים (מובייל, טאבלט, ומסכי מחשב רחבים).

2. **סימולטורים אינטראקטיביים חיים:**
   - **סימולטור חיתוך שקט (Timeline Cut Simulator):** הדמיה אינטראקטיבית של טיימליין לפני ואחרי חיתוך שקט בלחיצת כפתור אחת, המציגה חיסכון של מעל 60% מהזמן.
   - **סימולטור כתוביות AI לסרטוני סושיאל (Reels / TikTok / Shorts):** סליידר חי לכמות מילים במשפט (1 עד 8 מילים) המציג את הכתוביות המונפשות בתוך מוקאפ סמארטפון בזמן אמת.

3. **הורדה ישירה וקלה:**
   - כפתור הורדה ישיר של קובץ `cs-trim-v1.0.0.zip`.
   - החבילה כוללת סקריפט התקנה אוטומטי למק (`Install_Mac.command`) ול-Windows (`Install_Windows.bat`).

4. **מדריכי התקנה ושאלות נפוצות (FAQ):**
   - לשוניות הדרכה צעד-אחר-צעד למשתמשי Mac ו-Windows.
   - הסבר על התמלול המקומי (בלי מפתח API).
   - אקורדיון שאלות נפוצות עם מענה לכל החששות (חינמיות, דיוק בעברית, גרסאות פרמייר).

## 🚀 איך להעלות את האתר לרשת (בחינם ובתוך 2 דקות)?

ניתן לפרוס את האתר בכל שירות אחסון סטטי חינמי. הנה האפשרויות המומלצות:

### אפשרות 1: Vercel / Netlify (הכי מהיר ונוח)
1. היכנסו ל-[vercel.com](https://vercel.com) או [netlify.com](https://netlify.com).
2. גררו את תיקיית `website` ישירות לדשבורד (Drag & Drop).
3. האתר שלכם באוויר מיד עם כתובת אינטרנט מאובטחת (HTTPS) ואפשרות לחיבור דומיין מותאם אישית (למשל `cstrim.co.il` או `cstrim.com`).

### אפשרות 2: GitHub Pages
1. העלו את הפרויקט למאגר (Repository) ב-GitHub.
2. בהגדרות המאגר (Settings > Pages), בחרו בענף הראשי ובתיקיית `/website` (או העבירו את תכולת `website` לענף ייעודי `gh-pages`).
3. שמרו – והאתר יפעל בכתובת: `https://<username>.github.io/<repo-name>/`.

## 🛠 בדיקה מקומית במחשב

כדי לצפות באתר במחשב שלכם לפני ההעלאה לרשת:
1. פשוט לחצו לחיצה כפולה על הקובץ `website/index.html` כדי לפתוח אותו בכל דפדפן (Chrome, Safari, Edge, Firefox).
2. או הריצו שרת מקומי זריז דרך הטרמינל מתוך תיקיית הפרויקט:
   ```bash
   python3 -m http.server 8000 --directory website
   ```
   ופתחו בדפדפן: `http://localhost:8000`
